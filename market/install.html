dsh-sensitive-guard 安装命令

前置敏感内容拦截与脱敏插件 · 版本 1.7.7 · 点击右侧按钮复制

① 添加市场来源（推荐）

在 DSH 的 Plugins / Discover 页面「添加来源」，粘贴下方 URL，即可搜索并一键安装。

https://raw.githubusercontent.com/XGuai-S/dsh-sensitive-guard/main/market/index.json

② 命令行安装（GitHub 最新版）

把 web 换成你的 profile 名称。

dsh plugin --profile web add github:XGuai-S/dsh-sensitive-guard

③ 命令行安装（固定版本 · 可复现）

锁定到当前索引指向的精确 commit，适合脚本与团队统一。

dsh plugin --profile web add github:XGuai-S/dsh-sensitive-guard#f5eaf91a4493129b65f55a85a3e9018f5bd195d5

④ 安装本目录（本地源码）

或在 DSH 的 插件 → 添加插件 中选择本目录。命令行如下：把 web 换成你的 profile 名称。

dsh plugin --profile web add C:\Users\XGuai-S\Downloads\a\dsh-sensitive-guard

源码：github.com/XGuai-S/dsh-sensitive-guard
